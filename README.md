### 4. Prerequisites & Local Development

#### Prerequisites
- Ruby 3.3+ (Ruby 3.4 recommended), Bundler

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-rails.git
cd Portfolio-Rails
bundle install
```

#### Running Development Server
```bash
bin/rails server -b 0.0.0.0 -p 3000
```

#### Production Build
```bash
bin/rails assets:precompile
```

#### Running Test Suite
```bash
bin/rails test
```
