# Reginald Alfret V - Portfolio (Ruby on Rails 8 Edition)

> Fully server-side rendered Ruby on Rails implementation of Reginald Alfret's obsidian liquid-glass resume portfolio with 30 merged open-source PRs across Google, Apple, Microsoft, Meta, AWS, NVIDIA, NASA, and Netflix.

## Tech Stack
- **Framework:** Ruby on Rails 8.1.4.1 (Ruby 3.4.12)
- **Architecture:** Ruby MVC · ActionView · ERB SSR
- **Styling:** Tailwind CSS (Dark obsidian / Ruby crimson glow)
- **Deployment:** Vercel Static Export & Local WEBrick / Puma

## Multi-Stack Showcase
Part of Reginald Alfret's 6-stack portfolio architecture:
1. **Next.js 14** (TypeScript, React, App Router)
2. **Nuxt 3** (Vue 3, TypeScript, Vite)
3. **Django 5.2** (Python 3.13, Django MVT)
4. **Spring Boot 3.4** (Java 21, Spring MVC, Thymeleaf)
5. **Laravel 12** (PHP 8.4, Blade SSR)
6. **Ruby on Rails 8** (Ruby 3.4, ActionView ERB)

## Local Setup
```bash
# Clone
git clone https://github.com/reginaldalfret/portfolio-rails.git
cd portfolio-rails

# Install dependencies
bundle install

# Run server
ruby bin/rails server -p 8084
```
Navigate to `http://localhost:8084`.
